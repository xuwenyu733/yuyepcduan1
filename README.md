# 渔业 PC 端（yuyepcduan1）

本仓库包含：

- `kede_front_0816_副本`：前端（水质 / 大屏 / 专家会议入口等）
- `kd-backend2 2`：yudao 后端
- `ai-xiaoke`：AI 小科（llm-proxy + Skills 知识）
- `rtc_kede`：专家会议 RTC

> 数据库 dump（如 `yudao1.sql`）不入库，请本地自行导入。

## 智能图文录入与查询

- 登录后，各业务页面共用右下角的 AI 助手入口。
- “录入数据”在现有 AI 助手区域内显示，支持文字与多张原图一起保存到 MySQL，并查看已存资料。
- “查询分析”按数据库已有内容、联网查询相关内容、数据库与网络综合总结三块展示结果。
- 未配置模型时，第三块明确展示资料摘录汇总；图片原件可查看，目前不自动识别图片内容。

首次部署需要执行新增表的 SQL，并配置前端、Java 后端与 AI 小科服务之间的地址。详见 [图文录入部署与验证说明](docs/smart-entry.md)。
