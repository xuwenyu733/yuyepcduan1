# 企业鱼类知识 / Skills

## 两个目录

| 目录 | 用途 |
|------|------|
| `rules/` | 系统内置示例规则（只读建议） |
| `skills/` | **知识录入页**保存的原生 Markdown Skill（可增删改） |

小科回答时会同时读取这两处。**命中规则（樊总）**：用户问题只要命中某条经验的**至少两个关键词**（`tags`），就参考该经验；再按命中数与权重排序，并用联网资料补充。

## 给不懂技术的人

打开页面顶部 **「知识录入」**（`#/skills`）：

1. 填标题、标签、重要程度  
2. 用大白话写正文  
3. 点「保存为 MD Skill」  

系统会自动生成 Markdown 并写入 `skills/`。

## 手动写 MD 也可以

```md
---
id: my-skill
title: 规则标题
weight: 10
tags: 水质,溶氧
---

正文……
```
