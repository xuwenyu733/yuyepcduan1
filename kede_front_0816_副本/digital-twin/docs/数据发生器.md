# 本地数据发生器说明

本 Demo 使用本地 **SQLite** 持续 `INSERT` 设备遥测，供孪生页面动态刷新。  
（未对接韦度 PMIS；字段命名已对齐 `device_code` / `pool_code` / `workshop`，便于以后迁移。）

## 启动

```bash
npm run api          # 仅发生器 :8787
npm run dev          # API + 前端一起
```

环境变量：

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `PORT` | `8787` | API 端口 |
| `GENERATOR_INTERVAL_MS` | `2000` | 全设备写入间隔 |

## 库表

- 文件：`data/twin_telemetry.sqlite`
- 表：`device_telemetry`
- 约每 **5 秒** 为全部设备各写 1 行；约每 5 分钟清理超 5 万行的旧数据
- 前端每 **4 秒** 软刷新列表指标（不全量重建 DOM）；历史仅在「动态」页签低频拉取


## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 行数、间隔 |
| GET | `/api/devices/latest` | 当前内存快照 |
| GET | `/api/devices/:code/history` | 入库历史 |
| POST | `/api/devices/:id/action` | 开关/启停/投喂等 |

前端通过 Vite 代理访问 `/api/*`。发生器未启动时，前端自动退回浏览器内模拟数据。
